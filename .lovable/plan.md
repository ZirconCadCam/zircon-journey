# استقلال مركز زركون CAD CAM على Vercel

## النتيجة المطلوبة
تشغيل https://zircon-journey-main.vercel.app/ بقاعدة بيانات وحسابات وملفات مستقلة عن Lovable Cloud، بدءاً من أحدث بيانات النسخة المنشورة. توقف Lovable Cloud بعد النقل لا يوقف خدمات البيانات في Vercel؛ لا يمكن ضمان عدم انقطاع الخدمة المستقلة نفسها.

## ما يلزم منك أولاً
- إنشاء مشروع في خدمة Supabase مستقلة تملك حسابها؛ هذا مشروع جديد خارج Lovable Cloud، وله تكاليفه وحدوده الخاصة.
- توفير وسيلة آمنة لإعداد متغيرات Vercel؛ لا ترسل المفاتيح السرية في المحادثة.
- السماح بتشغيل Lovable Cloud مؤقتاً للتصدير إذا كانت متوقفة. لن تُستأنف تلقائياً.

## خطوات النقل
1. تصدير قاعدة بيانات المشروع الحالي من **More → Database → Manage → Settings → Export data** أثناء تشغيل السحابة، وتنزيل ملفات التخزين بشكل منفصل من **More → Storage**. التصدير يشمل الحسابات وكلمات المرور المشفرة، ولا يشمل الملفات أو الأسرار أو إعدادات تسجيل الدخول.
2. استعادة التصدير إلى المشروع المستقل ونقل الملفات، ثم مطابقة الجداول والصلاحيات وإعدادات تسجيل الدخول مع التطبيق. تجنب تشغيل إرسال تلجرام في النسختين بالتوازي أثناء الانتقال.
3. ضبط متغيرات المتصفح والخادم في Vercel على المشروع الجديد، وإعداد الخدمات الأخرى والمهام المجدولة اللازمة دون تغيير ربط بوت تلجرام الحالي.
4. التحقق من ربط GitHub بفرع الإنتاج نفسه في Vercel حتى تنشر تعديلات الكود تلقائياً. ضبط الربط يتم من حسابات Lovable وVercel، وليس من تعديل الكود وحده.
5. عند الانتقال النهائي، إيقاف إدخال البيانات مؤقتاً في النسخة القديمة وأخذ تصدير نهائي متاح وفق حدود الخدمة، لتجنب فقد التغييرات بين التصدير والانتقال.
6. اختبار تسجيل الدخول، عرض الشهور والكشوف، حفظ حالة وقراءتها، رفع وتنزيل ملف، والتقارير والإرسال من نسخة Vercel. بعد نجاح التحقق تكون Vercel مصدر العمل والبيانات.

## التحديثات بين النسختين
- GitHub يزامن الكود فقط؛ لا يزامن قاعدة البيانات أو الملفات.
- تبدأ Vercel ببيانات التصدير النهائي، ثم تُحفظ أعمالها الجديدة في القاعدة المستقلة.
- لن نضيف مزامنة كتابة ثنائية بين قاعدتين؛ تتطلب معالجة تعارضات منفصلة وقد تكرر الحالات والإرسال. النسخة القديمة لن تستقبل تلقائياً بيانات Vercel الجديدة.

## تفاصيل تقنية
- استخدام إعداد Vercel الحالي وإبقاء إعداد نشر Lovable منفصلاً.
- لا تعديل للملفات المولدة تلقائياً، ولا نتائج فحص الأمان المتبقية، ولا متغيرات Lovable Connectors.
- مفاتيح المشروع المستقل تُضبط في Vercel؛ مفتاح الخدمة الخاص بـ Lovable Cloud غير متاح ولا يُطلب استخراجه.
- لا تغيير للكود أو البيانات قبل توفر الخدمة المستقلة والتصدير والوصول اللازم للتحقق.
